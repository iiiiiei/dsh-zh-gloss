# 02 · 使用指南

## 应用内开关

安装后打开 **设置 → 通用设置 → 语言** 行：语言选择按钮左侧会出现一枚
「汉化：开 / 汉化：关」按钮（视觉借用官方药丸样式，随官方改版自动跟随）。

- **关**：立即停用翻译并逐字节还原官方原样（词典缓存保留，重开更快），无需刷新；
- **开**：立即恢复翻译，同样无需刷新；
- 状态持久化于浏览器 localStorage，重启服务器、重装插件后跟随；
- 真正的 cordis 卸载（见 [01-一键安装](01-一键安装.md)）会连开关一起移除。

## 插件注释

**设置 → 插件 → 插件列表**：展开任意插件卡片，会出现一行
「描述：……」——官方列表本身不渲染 package.json 描述，这一行由本插件注入。

- 全量覆盖插件列表可见的 169 个插件（154 条词典收录 + 别名映射），
  译文依据各包 `package.json` 官方英文原文校准；
- 已挂载与已停用的插件都会注入（分别锚定「Cordis 状态」行与「配置状态」行）；
- 注入位置与样式跟随官方卡片结构（dl/dt/dd 网格），官方改版自动适配。

## 词典热更新（不重启、不重装）

想补一条翻译、改一处措辞：

```bash
$EDITOR ~/.dsh/profiles/node_modules/dsh-l10n-zh/dicts/literals.json
# 保存后刷新网页（Cmd+R）即可
```

三层词条语法（按场景选层）：

| 层 | 文件 | 适用 | 例子 |
|---|---|---|---|
| 键级覆盖 | `dicts/ui.json` | 走官方 t() 但 zh 值缺失/未译 | trajectory 工具栏 |
| 字面量精确 | `dicts/literals.json` 等 | 硬编码英文、后端下发静态串 | System Prompt |
| 模式匹配 | 同上 `patterns[]` | 带路径/数字的动态串 | `Compacted N history items (~X tokens).` |

另外两个专用层：`chromeLiterals`（Read/Write/Edit 这类通用词，只在按钮/标题
等界面骨架内生效，永不误伤聊天内容）；`pluginInfo`（插件注释，键为插件 id）。

**怎么找到该补哪条**：DevTools 选中漏网文案元素，复制**完整**文本（含标点）；
若含变化部分（路径/数字），按模式语法写条目，`$1~$9` 引用捕获组。
删词条 = 该处回退英文原件。

## 覆盖范围速览

| 场景 | 状态 |
|---|---|
| 轨迹时间线徽章/计数（用户消息/助手消息/系统提示词/工具调用/第 N 轮/请求 #N） | ✅ |
| 轨迹详情面板（状态/已完成/Token 数/预览/请求耗时/用量/耗时页签全字段） | ✅ |
| 斜杠命令释义 ×7 + 执行回执 30+ | ✅ |
| 权限预设名+描述（只读/工作区写入/完全访问） | ✅ |
| 工具卡片标题（读取/写入/编辑/抓取/检查/工具调用） | ✅ |
| 插件列表描述（169 全量） | ✅ |
| 官方已汉化的部分 | 不重复处理，官方优先 |
| 用户聊天内容、代码块、路径、命令输出 | 永不翻译 |
| macOS 原生文件面板（"访达"弹窗本体） | 系统级，网页插件不可达（其宿主报错串已覆盖） |
| 工具名 bash/read/edit、单位 tok/s、TTFT | 有意保留 |

完整清单与边界声明见 [`reports/value-gaps.txt`](../reports/value-gaps.txt)
与 [`wiki` 各报告](../reports/)。

## 语言跟随

仅当界面语言为**中文**时生效；English 模式下插件零行为（词典不加载、DOM 不扫描）。
官方后续补齐某处中文译文时，键级覆盖**自动让位**给官方版本（追赶自愈）。
