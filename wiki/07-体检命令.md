# 07 · 体检命令（Doctor）

只读体检三件套，任何时候怀疑插件状态异常都可按序执行。

## 1. 服务器侧状态

```bash
curl -s localhost:3080/api/l10n-zh/status | python3 -m json.tool
```

```jsonc
{
  "ok": true,                    // 插件已加载且路由就绪
  "plugin": "dsh-l10n-zh",
  "dictsDir": "…/dsh-l10n-zh/dicts",
  "officialDshVersion": "0.1.1-rc.2",  // 探测到的官方版本（null=探测不到）
  "pluginBaseline": "0.1.1-rc.2",      // 插件验证基线
  "drift": false,                // true=官方已偏离基线，建议重跑扫描器；null=无法探测
  "files": [                     // 词典文件清单；解析失败的会带 error 字段
    { "file": "10-backend-copy.json", "mtimeMs": … },
    …
  ],
  "literalCount": 116,           // 合并后的词条计数
  "patternCount": 18,
  "pluginInfoCount": 154
}
```

**判读**：`ok:false` 或 404 → 插件未加载（检查 patch.yml 与进程启动时间）；
`files[].error` → 对应词典 JSON 写坏了，其余文件不受影响；`drift:true` →
见 [05-更新机制](05-更新机制.md)。

## 2. 词典内容抽查

```bash
curl -s localhost:3080/api/l10n-zh/dicts | python3 -m json.tool | less
```

确认你的新词条已在线（编辑词典后无需重启，此接口每次现读磁盘）。

## 3. 客户端侧（浏览器）

- 设置 → 通用设置 → 语言行左侧有「汉化：开/关」按钮 → 客户端模块已激活；
- 想看注入器内部轨迹：控制台 `localStorage.setItem("dsh-l10n-zh:debug","1")`
  刷新后读 `window.__l10nDebug`。

## 4. 离线自测（仓库内）

```bash
node tests/selftest.mjs     # 123 项全过 = 插件本体逻辑健康
```

## 快速故障对照

| 症状 | 第一步检查 |
|---|---|
| /status 404 | patch.yml 的 insert 段 + 服务器进程启动时间（旧进程占端口是最常见根因） |
| 界面部分英文 | /status 的 drift + `tools/scan-locale-gaps.mjs`；新文案补词条 |
| 开关不见了 | 官方设置页结构变更 → debug 探针看锚点；翻译不受影响 |
| 个别插件无描述 | 该插件 id 未收录（对照 /dicts 的 pluginInfo 段） |
| 怀疑冲突 | 应用内开关关闭对比；或按 [01](01-一键安装.md) 完全卸载对照 |
