# 06 · 安全与风险

## 代码触面（全部可审计）

本插件**没有**构建步骤、没有压缩、没有第三方依赖——两个 JS 文件即全部运行时代码，
逐行可读：

| 文件 | 行数 | 干什么 |
|---|---|---|
| `plugin/lib/index.js` | ~200 | 宿主侧：读 `dicts/*.json` 并应答两个只读 GET 路由 |
| `plugin/lib/client.js` | ~740 | 浏览器侧：lookup 包裹 + MutationObserver 扫描 + 设置页注入 |

## 攻击面分析

- **网络**：只监听已存在的 dsh webServer（127.0.0.1），新增两条**只读**路由；
  不接受 POST/写操作、不接收外部输入（`?t=Date.now()` 仅用于防缓存）。
- **文件系统**：只读 `dicts/` 目录（自身目录内）；不写任何文件。
- **DOM**：只改写文本节点与 4 个展示属性（title/aria-label/placeholder/
  aria-description）；不注入 script、不 eval 页面内容、不触碰表单值；
  代码区/用户气泡有硬护栏。
- **凭据**：不读取 cookie/token/会话内容；localStorage 只存词典缓存与本插件
  开关状态（无敏感信息）。
- **词典正则**：来自本地 JSON 文件；坏正则在编译期跳过并 console.warn，
  不会 ReDoS 页面（条目均为短锚定模式，无嵌套量词）。

## 供应链与信任

- 零 npm 运行时依赖 → 无依赖链投毒面；
- `tools/scan-locale-gaps.mjs` 使用 `eval` 解析官方包内字典字面量——
  这是**本地开发工具**，仅应针对本机已安装的官方包运行，勿对不可信来源的
  bundle 使用（代码内有注释标明信任边界）；
- 词数据可被任何人审阅（纯 JSON），欢迎对译文提 PR。

## 风险声明

> [!WARNING]
> - 本插件为**非官方社区项目**，与 DeepSeek 官方无关联；官方不对其行为背书。
> - 插件直接操作 Web UI 的 DOM 与 `LocaleRuntime.lookup`。官方 dsh 处于
>   开发者预览期（可能有破坏性变更），升级后请按 [05-更新机制](05-更新机制.md)
>   体检。最坏情形为翻译失效（fail-inert 设计保证不会白屏/崩溃）。
> - 若你把 dsh webServer 暴露到非回环地址，本插件的两个只读路由会同样暴露
>   （仅泄露词典内容，无敏感数据），但请自行评估整体暴露面。

## 隐私

无遥测、无上报、无外部请求。词典 fetch 只发往本机 dsh 服务器。
