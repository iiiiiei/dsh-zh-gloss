# 01 · 一键安装

> 本章面向使用者：从拿到本仓库到 Web UI 出现中文，全程约 2 分钟。
> 开发者贡献流程见 [04-构建与发版](04-构建与发版.md)。

## 前置条件

| 依赖 | 要求 | 检查命令 |
|---|---|---|
| dsh | `@deepseek-ai/dsh@0.1.1-rc.2`（npx 形态） | `ls ~/.npm/_npx/*/node_modules/@deepseek-ai/dsh/package.json` |
| Node.js | ≥ 20（dsh 自身要求） | `node -v` |
| DSH home | `~/.dsh` 已初始化（启动过一次 dsh） | `ls ~/.dsh/profiles` |

## 三步安装

### 第 1 步 · 拿到插件目录

```bash
git clone https://github.com/iiiiiei/l10n-zh.git
cd l10n-zh
bash scripts/pack.sh        # 语法校验 + 词典校验 + 123 项自测 + 打包
# 产物：dist/dsh-l10n-zh/
```

> [!TIP]
> 不想 clone 也可以直接下载 [Releases](https://github.com/iiiiiei/l10n-zh/releases)
> 里的 `dsh-l10n-zh-<版本>.tar.gz` 解包，效果等同。

### 第 2 步 · 装进 web profile

```bash
cp -R dist/dsh-l10n-zh ~/.dsh/profiles/node_modules/
```

然后编辑 `~/.dsh/profiles/web/cordis.patch.yml`，在末尾追加（保留原有条目）：

```yaml
- insert:
    - id: l10n-zh
      name: 'dsh-l10n-zh'
```

### 第 3 步 · 重启并验证

重启 dsh 服务器（DSH Desktop：菜单「服务器 → 重启」；命令行：重启 `dsh web` 进程），
浏览器打开 Web UI 后体检：

```bash
curl -s localhost:3080/api/l10n-zh/status | python3 -m json.tool
```

看到 `"ok": true` 即生效。最后确认设置 → 语言为「中文」。

> [!IMPORTANT]
> 重启后务必核对进程是新启动的：`ps aux | grep dsh/lib/bin.js` 看启动时间。
> 旧进程若未退净会占住 3080 端口，新进程将静默退出，你会误以为装上了旧版。

## 升级已安装版本

```bash
cd l10n-zh && git pull
bash scripts/pack.sh
rm -rf ~/.dsh/profiles/node_modules/dsh-l10n-zh
cp -R dist/dsh-l10n-zh ~/.dsh/profiles/node_modules/
# 重启服务器 → 刷新网页
```

## 卸载（随时，完全还原）

```bash
# 1. 删掉 cordis.patch.yml 里的 l10n-zh insert 段（共 3 行）
$EDITOR ~/.dsh/profiles/web/cordis.patch.yml

# 2. 删除插件目录
rm -rf ~/.dsh/profiles/node_modules/dsh-l10n-zh

# 3. 重启服务器 —— UI 与从未安装时逐字节一致（有自动化测试保证）
```

原理与可逆性证明见 [03-架构与原理](03-架构与原理.md)。
